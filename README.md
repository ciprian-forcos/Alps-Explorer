# 🏔️ Alps Explorer

An interactive map of ski resorts and investment villages across the French & Italian Alps.

## Features

- 22 ski resorts mapped with piste data, altitudes, and official links
- 17 companion villages with buy ratings and live property listing links
- Toggle resorts / villages independently
- Filter by France or Italy
- Switch between Street, Terrain, and Satellite map styles
- Click any marker for full details and links

## How to deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `alps-explorer`)
1. Upload `index.html` to the repo root
1. Go to **Settings → Pages**
1. Set Source to **Deploy from branch → main → / (root)**
1. Save — your site will be live at `https://yourusername.github.io/alps-explorer`

## Data sources

- Ski resort data: Les2Alpes.com, SkiResort.info, Wikipedia
- Property links: Rightmove, Immobiliare.it, Idealista, French Estate Agents (Leggett)
- Maps: OpenStreetMap, OpenTopoMap, Esri World Imagery
